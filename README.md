# Dinesh Tamang
## Tax Calculator

It calculates tax of annual income. $0 - $5k they are taxed 5% and 5k-10k is 15% anything above 10k is 20%.

## Built With
- Python
- Flask
- HTML/CSS

## Running Locally
1. `pip install flask`
2. `python app.py`
3. Open `http://127.0.0.1:5000/` in your browser
